JanitorAI 连接设置

在聊天的 API Settings 中选择 Proxy，添加并启用配置。

Model Name：填写你的 Vertex AI 项目可用的 Gemini 模型，例如 gemini-2.5-flash。

Proxy URL：填写此服务的网址；使用 /quiet/ 可隐藏更新横幅。

API Key：填写代理管理员提供的访问口令；未限制访问时可使用固定的用户标识。

保存后点击 Test。保持同一个 Key，才能保留你的命令设置。
